③ Agent 主循环（local_conversation.py）

用户 send_message() → 事件入列
while True: agent.step() ＋ 状态机（RUNNING/PAUSED/STUCK/确认/FINISHED/ERROR）
step 内部：待确认动作 → hook 检查 → condenser 上下文压缩 → llm.generate(tools=…)
解析 function calls → ParallelToolExecutor 并行执行 → Observation 事件回填
兜底：卡死检测 / 最大迭代 / 预算超限 → FINISHED 或 ERROR
↺ Observation 喂回下一轮，直到模型不再要工具 = 一次 run() 结束

⑤ 自测卡

Q1：OpenHands 现在还是"纯 Python 项目"吗？
看答案
不是。2025-08 拆仓后主仓是 TS/React 的 Agent Canvas（控制台），Python 内核在独立仓 software-agent-sdk。
Q2：它的主循环和我说的"300 行迷你内核"什么关系？
看答案
同构。while True + step（压缩→调 LLM→并行工具→回填）+ 状态机兜底；官方 hello world 20 行就能跑通这个循环的库版本。
Q3：为什么 Agent Canvas 能跑 Claude Code/OpenCode 当后端？
看答案
靠 ACP（Agent Client Protocol）开放协议 + Agent Server HTTP API，界面与内核解耦后任何 ACP 兼容 agent 都能插。
Q4：对 DGA 最值得抄的三个设计？
看答案
①事件溯源落盘（审计日志）②confirmation mode（审批门）③condenser（长对话压缩）。
